# MyQuant 文档增量下载器

## 安装

1. 用 Chrome 正常登录 MyQuant，并打开 `https://www.myquant.cn/docs2/`。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本目录。
4. 刷新 MyQuant 文档页，点击扩展图标，再点击“扫描并增量下载”。

文件会保存到 Chrome 默认下载目录下的 `myquant-docs/`。

## 增量规则

扩展保存每个 URL 的 SHA-256 内容哈希。下次扫描会重新读取可访问页面；内容和文件路径都没有变化的页面不会再次下载。失败页面会显示在结果中，并且不会被标记为成功。

## 注意

- 扩展不会读取或保存密码，只使用当前 MyQuant 标签页的登录会话。
- 首次扫描必须保持文档标签页打开。
- 这是文档下载器，不会调用行情接口、下单或修改 MyQuant 账户状态。
- 请确认下载和保存行为符合 MyQuant 账号协议及文档版权许可。
