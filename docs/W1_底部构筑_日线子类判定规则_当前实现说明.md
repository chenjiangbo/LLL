# W1 底部构筑：日线子类判定规则（当前实现说明）

本文描述当前项目 `backend/screening/technical_classifier.py` 的实际执行逻辑，适用于分类器版本 `TECH_CLASSIFIER_V1_0`。设计基准见《全市场技术形态分类系统_周线W1-W4与日线子类量化规则_V1.0.md》。

## 1. 前提与输出

只有周线阶段已经判为 `W1_BASE`（底部构筑）的股票，才会进入本页规则。每只股票在每个交易日最多输出一个 W1 日线子类：

| 子类代码 | 页面中文名 | 含义 |
| --- | --- | --- |
| `W1_BASE_RANGE` | 底部箱体 | 筑底背景下暂无更具体信号的默认状态 |
| `W1_BASE_COMPRESSION` | 底部压缩 | 价格与均线同时收敛 |
| `W1_EARLY_PREP` | 底部早期准备 | 下跌/回撤后出现初步修复，但未正式转强 |
| `W1_FIRST_TURN` | 首次转强 | 筑底区内的有效日线启动 |
| `W1_BREAKOUT` | 底部突破 | 价格向上脱离底部箱体 |
| `W1_BREAKOUT_PULLBACK` | 突破后回踩 | 突破后回踩关键位的确认阶段 |
| `W1_BREAKOUT_REACCEL` | 突破再启动 | 回踩后重新向上加速 |
| `W1_FAILED_BREAKOUT` | 突破失败 | 突破有效性被破坏 |

`setup_score` 只会在“早期准备”或“首次转强”类型上计算；其余 W1 子类当前不产生机会评分。

## 2. 公共指标口径

- `price`：前复权收盘价 `adj_close`。
- `base_upper`：当前日前最多 60 个交易日的最高前复权收盘价；不含当前日。
- `volume_ratio`：当前成交量相对均量的比值。
- `retake_count`：价格重新夺回均线/关键位的累计次数。
- `order_score`：均线多头排列得分。
- `ma_spread_atr`：MA5、MA10、MA20、MA30 最大差除以 ATR20，越小表示均线越收敛。
- `cross_pair_count_10d`：近 10 日均线交叉对数。
- `extension_atr`：价格相对均线的 ATR 偏离程度。
- `arc`（均线开始画弧）：下列四项至少两项成立：

  - `ma10_slope >= -1%`
  - `ma20_slope >= -1.5%`
  - `ma10_curve_improve >= 0.8%`
  - `ma20_curve_improve >= 0.8%`

- `converge`（均线靠拢）：`ma_spread_atr <= 1.2`，或 `spread_contract_ratio <= 0.85`，或 `cross_pair_count_10d >= 1`。
- `first_turn`（首次转强公共条件）：`retake_count >= 3`、`order_score >= 2`、`MA5 > MA10`，且 `ma_spread_atr <= 1.2` 或 `cross_pair_count_10d >= 2`。

## 3. 各子类判定

### 3.1 底部箱体 `W1_BASE_RANGE`

默认分类。当下面所有更高优先级的 W1 条件均不成立时，输出底部箱体。

### 3.2 底部压缩 `W1_BASE_COMPRESSION`

同时满足：

```text
ma_spread_atr <= 0.80
20 日价格振幅 <= 12%
cross_pair_count_10d >= 2
```

其中当前代码的 20 日价格振幅为：

```text
(近 20 日最高收盘价 - 近 20 日最低收盘价) / 近 20 日平均收盘价
```

### 3.3 底部早期准备 `W1_EARLY_PREP`

先满足位置/回撤条件之一：

```text
drawdown_20d >= 5%
或 range_pos_60d <= 0.60
```

再同时满足：

```text
arc = true
converge = true
retake_count >= 1
extension_atr <= 1.5
first_turn = false
```

含义：均线和价格开始修复，但尚未达到正式启动的强度。

### 3.4 首次转强 `W1_FIRST_TURN`

满足公共 `first_turn`：

```text
retake_count >= 3
order_score >= 2
MA5 > MA10
且（ma_spread_atr <= 1.2 或 cross_pair_count_10d >= 2）
```

### 3.5 底部突破 `W1_BREAKOUT`

满足任一分支：

```text
price >= base_upper * 1.01
且 volume_ratio >= 1.20
```

或：

```text
连续两日收盘价都高于前 60 日箱体上沿
```

首次满足时，系统记录 `breakout_level`、`breakout_date` 与 `breakout_high`，并建立突破 Episode。

### 3.6 突破后回踩 `W1_BREAKOUT_PULLBACK`

V1 设计口径为：已有突破后，回撤距离突破以来高点至少 4%，同时价格位于：

```text
breakout_level * 0.97 <= price <= breakout_level * 1.05
```

### 3.7 突破再启动 `W1_BREAKOUT_REACCEL`

V1 设计口径为：已处于突破后回踩状态，且：

```text
retake_count >= 3
ma5_slope > 0
price >= breakout_level
price > 前 5 日最高收盘价
```

### 3.8 突破失败 `W1_FAILED_BREAKOUT`

已有突破 Episode 后满足任一：

```text
连续两日 price < breakout_level * 0.97
```

或：

```text
price < MA30
且 price < breakout_level * 0.97
```

系统将 Episode 置为 `FAILED`。这不强制周线立即转为 W4；周线仍按独立的慢变量规则判断。

## 4. 当前代码的执行优先级

实现从上到下使用 `elif`，优先顺序为：

```text
已突破且跌破 3% → 突破 / 突破失败
已突破 → 突破
已失败 → 突破失败
（设计中的）突破后回踩
（设计中的）回踩后再启动
突破后深度回落 → 突破失败
新突破
首次转强
早期准备
底部压缩
底部箱体
```

## 5. 已发现的实现差异（需修复后才会生效）

当前代码在“已突破”后，先无条件返回 `W1_BREAKOUT`，再判断“突破后回踩”和“回踩后再启动”。因此后两段 `elif` 在现有顺序中不可达。

影响范围：

- 当前全市场快照中 `W1_BREAKOUT_PULLBACK` 与 `W1_BREAKOUT_REACCEL` 的数量可能长期为 0 或无法按设计产生；
- 原本应处于回踩或再启动的股票，会继续被标记为“底部突破”；
- `W1_FAILED_BREAKOUT` 仍可按跌破条件产生。

这份文档没有改动分类方案或规则，只记录当前实现与 V1 设计之间的差异。若要修复，应把“突破后回踩 / 再启动”判断放到“已突破默认输出”之前，并对 W1 Episode 全量重建快照后校验结果。
