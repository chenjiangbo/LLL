**哪些长期弱势股票，已经从“继续下跌”进入“下跌衰竭—筑底—即将转强”的阶段？**

所以它应该比正式 A 池**早一个阶段**。

你现在正式 A 池大致已经到了：

底部形成 → 短周期突破 → 日线明显转强。

A-Pre 则应该抓：

**下跌还没完全反转，但继续下跌的力量明显减弱，底越来越像底，而且资金/相对强度开始发生边际变化。**

---

# 一、我先把 A-Pre 的状态定义得非常明确
一只股票进入 A-Pre，最好同时具有四个性质：

1. **此前确实弱过**
2. **现在跌不动了**
3. **开始出现筑底迹象**
4. **还没有明显突破，不能已经涨一大截**

所以逻辑不是：

“价格低 = A-Pre”

而是：

**长期弱势 + 下跌衰竭 + 底部形成中 + 早期转强迹象**

我建议第一版全部用**日线数据**实现。

30分钟以后可以加，但不要让 A-Pre 依赖30分钟数据，否则工程复杂度很高，而且历史回测也麻烦。

---

# 二、第一部分：它必须真的经历过一段弱势
否则很多正常上涨趋势的小调整也会被误抓进来。

我建议定义三个指标。

### 1. 250日回撤
```plain
drawdown_250 =
close / max(high, 250日) - 1
```

例如：

历史高点 20元  
现在 12元

就是：

-40%。

初始条件可以：

`drawdown_250 <= -25%`

也就是至少离过去一年高点有25%左右距离。

不是说25%一定正确，而是先保证：

它确实属于“弱势后修复”这一类。

---

### 2. 过去250日价格位置
```plain
position_250 =
(close - low_250) /
(high_250 - low_250)
```

范围 0～1。

例如：

+ 0 = 年度最低点附近
+ 1 = 年度最高点附近

A-Pre 可以要求：

`position_250 <= 0.50`

更严格可以 0.4。

也就是仍处于过去一年价格区间的下半部分。

---

### 3. 中期趋势不能本来就是明显牛市
例如：

```plain
ret_120 = close / close_120d_ago - 1
```

可以要求：

`ret_120 < +10%`

或者 MA120 仍然没有明显大幅向上。

这条不用特别严格。

因为核心只是防止：

一只已经涨了一倍、最近回调20%的股票跑进 A-Pre。

这种应该属于 B 池，不是 A。

---

# 三、最关键：怎么量化“日线下跌速度明显减弱”
这个你问得特别好。

我不建议简单用：

最近20日跌幅小于最近60日跌幅。

因为周期不同，不能直接比较。

我更推荐用：

# 价格回归斜率
对最近 N 日的：

```plain
log(close)
```

做线性回归：

```plain
log(close) = a + b × day
```

其中 `b` 就是趋势速度。

计算：

+ `slope_60`
+ `slope_20`
+ `slope_10`

例如：

```plain
60日斜率 = -0.45% / 日
20日斜率 = -0.12% / 日
10日斜率 = +0.05% / 日
```

这就是一个非常典型的：

**长期下跌 → 下跌速度明显下降 → 短期开始微微向上。**

---

## 可以直接定义一个“下跌减速率”
假设 `slope60 < 0`：

```plain
deceleration =
1 - abs(min(slope20, 0)) / abs(slope60)
```

例如：

60日：

-0.4% / 日

20日：

-0.1% / 日

那么：

```plain
1 - 0.1 / 0.4 = 75%
```

说明：

**下跌速度已经下降75%。**

如果20日已经转正：

```plain
slope20 > 0
```

则可以认为：

`deceleration = 100%`

---

## 第一版我建议
满足：

```plain
slope60 < 0
```

并且：

```plain
deceleration >= 50%
```

就开始加分。

如果：

```plain
slope20 >= 0
```

进一步加分。

如果：

```plain
slope10 > slope20
```

再加分。

这样你就真正把：

“跌势正在越来越慢”

量化出来了。

---

# 四、第二个非常重要的概念：低点是不是越来越难创新低
这可能比均线金叉还重要。

我会先用一个非常简单、很稳定的版本。

定义：

```plain
previous_low =
前11～30交易日最低价

recent_low =
最近10交易日最低价
```

比较：

```plain
low_ratio =
recent_low / previous_low - 1
```

例如：

上一阶段最低：

10元

最近10日最低：

9.95

那么：

-0.5%。

意味着：

虽然还创了一点新低，但已经基本没有明显杀跌能力。

---

## 可以分三级
### 仍在明显创新低
```plain
low_ratio < -3%
```

不加分甚至扣分。

---

### 双底/基本不创新低
```plain
-2% <= low_ratio <= +2%
```

明显加分。

这就是程序意义上的：

**近似双底。**

---

### 出现更高低点
```plain
low_ratio > +2%
```

进一步加分。

这意味着：

第二波下跌已经跌不到前低。

非常值得关注。

---

# 五、第三个：波动是不是在收缩
底部经常会经历：

大跌大涨 → 波动逐渐缩小 → 买卖力量趋于平衡。

我们可以计算：

### ATR 收缩
```plain
atr_ratio =
ATR20 / ATR60
```

如果：

```plain
ATR20 / ATR60 < 0.85
```

说明近期波动比过去明显降低。

如果：

```plain
< 0.70
```

更明显。

---

还可以看价格区间：

```plain
range20 =
(max(high,20) - min(low,20)) / close
```

然后：

```plain
compression =
range20 / range60
```

如果：

```plain
compression < 0.55
```

说明最近20日价格活动范围明显压缩。

这就是很典型的：

**底部收敛。**

---

# 六、第四个：卖盘是不是开始衰竭
这里就开始涉及成交额。

我们前面刚说过：

绝对成交额低并不一定坏。

A-Pre 真正想看到的是：

**跌的时候越来越没人卖，涨的时候开始有人买。**

可以计算：

### 上涨日成交额
最近20日：

```plain
up_amount =
上涨交易日平均成交额
```

### 下跌日成交额
```plain
down_amount =
下跌交易日平均成交额
```

得到：

```plain
volume_asymmetry =
up_amount / down_amount
```

例如：

上涨日平均：

5000万

下跌日平均：

3000万

那么：

```plain
1.67
```

是很有意思的。

---

第一版可以这样评分：

```plain
<0.8     弱
0.8~1.0  普通
1.0~1.2  略好
>1.2     明显积极
>1.5     强
```

不建议作为硬条件。

因为底部早期可能根本没有明显放量。

---

# 七、还有一个我很喜欢的指标：成交活跃度“边际变化”
例如：

```plain
amount_ratio_5_20 =
最近5日平均成交额 /
过去20日平均成交额
```

如果：

```plain
0.8
```

说明越来越冷。

如果：

```plain
1.2
```

说明资金参与开始提高。

如果：

```plain
1.8
```

已经明显放量。

对于 A-Pre，我反而喜欢：

**1.0～1.5 左右**

因为这是：

“开始有人进来了，但还没爆量启动。”

如果已经：

3倍成交量 + 大阳线突破

那可能已经不是 A-Pre 了，而是正式 A 池。

---

# 八、第五个：相对强度是不是开始提前改善
这个我认为非常重要。

很多真正的底部不是股票先大涨，而是：

大盘还在跌，它已经不怎么跌了。

比如过去20天：

沪深300：

-8%

某股票：

-1%。

股票虽然还是跌的，

但是它实际上已经非常强了。

所以：

```plain
RS20 =
stock_return_20 -
benchmark_return_20
```

还应该有：

```plain
Industry_RS20 =
stock_return_20 -
industry_return_20
```

---

更重要的是看：

# RS 是否在改善
比如：

60日行业相对收益：

```plain
-15%
```

20日：

```plain
-3%
```

10日：

```plain
+2%
```

这非常漂亮。

说明：

**它正在从弱于行业 → 接近行业 → 强于行业。**

我们可以定义：

```plain
RS_improvement =
RS20 - RS60_normalized
```

不过不同周期直接比较有点别扭。

实际实现我更建议使用**横截面排名**：

例如全市场：

```plain
RS60_rank = 25%
RS20_rank = 48%
RS10_rank = 72%
```

意思就是：

两个月前它属于弱股。

现在已经慢慢进入前30%。

这种：

**RS Rank 快速上升**

是 A-Pre 非常值得重视的东西。

---

# 九、第六个：短期均线开始“拐”，但不能已经完全多头
这和正式 A 池要区分。

A-Pre 不应该要求：

```plain
MA5 > MA10 > MA20
```

否则很可能已经晚了。

A-Pre 更关心：

### MA20 还向下，但下跌斜率减弱
例如：

```plain
MA20_slope_now > MA20_slope_10d_ago
```

甚至：

```plain
MA20_slope_now ≈ 0
```

很好。

---

### MA5开始转上
```plain
MA5_t > MA5_t-3
```

加分。

---

### 收盘重新站上MA10
```plain
close > MA10
```

加分。

但：

**不作为必须条件。**

因为我们就是想提前发现。

---

# 十、第七个：距离“真正突破”还有多远
这个特别有用。

假设我们定义近期阻力位：

```plain
resistance =
过去20～30日最高价
```

注意：

**不包含今天。**

然后：

```plain
distance_to_breakout =
close / resistance - 1
```

例如：

阻力：

10元

现在：

9.60元

就是：

-4%。

这个股票可能已经很接近正式启动。

---

我会重点关注：

```plain
-8% ～ 0%
```

这一区间。

如果：

```plain
-25%
```

说明底部虽然可能稳定，但离真正启动还比较远。

如果：

```plain
+5%
```

说明已经突破了。

那应该进入正式 A 池，而不是继续留在 A-Pre。

---

# 十一、所以我建议 A-Pre 不要只有“选中 / 不选中”
而是做三级状态

这会非常适合你每天观察。

## A-PRE-1：下跌衰竭
特点：

跌速明显下降，但底部结构还不清楚。

比如：

+ 长期弱势 ✅
+ slope 减速 ✅
+ ATR收缩 ✅
+ 仍偶尔新低
+ RS尚未明显改善

可以理解为：

**开始观察。**

---

## A-PRE-2：底部形成
特点：

+ 下跌明显减速
+ 不再明显创新低
+ 出现双底/更高低点
+ 波动收缩
+ RS开始改善
+ 成交结构改善

这时候已经值得认真看。

---

## A-PRE-3：临界启动
特点：

+ 底部结构成熟
+ MA5/MA10开始上拐
+ RS快速提升
+ 成交开始温和放大
+ 距离近期阻力 < 5%～8%
+ **但尚未正式突破**

这是你真正每天最应该看的：

**“可能马上从 A-Pre 进入正式 A 池”的股票。**

---

# 十二、我会给它做一个 100 分评分
第一版可以这样：

| 模块 | 分值 |
| --- | --- |
| 长期弱势背景 | 15 |
| 下跌减速 | 25 |
| 底部结构 | 20 |
| 波动/卖压收缩 | 15 |
| 相对强度改善 | 15 |
| 临近启动 | 10 |
| **合计** | **100** |


然后：

### `<55`
不进入 A-Pre。

### `55～64`
A-PRE-1

### `65～74`
A-PRE-2

### `>=75`
A-PRE-3

但必须：

**尚未进入正式 A 池。**

# 十三、给 AI coder 的逻辑可以简化成这样
```plain
首先确认长期弱势背景：

drawdown_250 <= -25%
或
position_250 <= 0.40

↓

计算下跌衰竭：

slope60
slope20
slope10
deceleration

↓

计算低点结构：

recent_low / previous_low

↓

计算波动收缩：

ATR20 / ATR60
range20 / range60

↓

计算成交结构：

up_amount / down_amount
amount5 / amount20

↓

计算相对强度改善：

RS10_rank
RS20_rank
RS60_rank

↓

计算启动距离：

close / resistance_20_30 - 1

↓

计算 A_PRE_SCORE

↓

分成：

PRE1 / PRE2 / PRE3

↓

一旦达到正式 A 池条件：

A-Pre → A
```

# 十四、有几个东西我反而不建议 V1 就加入
例如：

+ MACD金叉
+ KDJ
+ RSI超卖
+ MACD背离
+ RSI背离
+ 波浪计数

不是说它们完全没价值。

而是这些指标大量都是价格的不同变换，而且“背离”这种东西程序定义起来很容易越来越复杂。

我们的 A-Pre 第一版最好保持非常清晰：

**趋势减速 + 不再创新低 + 波动收缩 + 卖压下降 + RS改善 + 接近突破。**

这六件事情其实已经非常接近一个真正“底部正在成熟”的量化描述了。

---

还有一点我现在觉得非常重要：

**正式 A 池和 A-Pre 不能只是两个独立扫描器。**

系统应该保存状态迁移：

```plain
普通股票
↓
A-PRE-1
↓
A-PRE-2
↓
A-PRE-3
↓
A正式池
↓
Trigger
```

甚至记录：

股票在每个阶段待了多少天。

因为以后我们可以历史统计：

**哪些 PRE3 最容易进入 A？**

以及：

**哪些 PRE3 最终失败重新跌破底部？**

这样跑半年以后，A-Pre 本身就会越来越聪明。

我认为下一步最值得我们继续细化的是其中最核心的 **“底部结构”**：现在我上面用了一个很简单的“前低 vs 最近低点”，但实际上可以进一步量化成 **单底、双底、更高低点、底部箱体、假跌破后收回** 几种结构，这会明显提升 A-Pre 的质量。
