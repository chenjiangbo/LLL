# A / B / C 三类候选池量化变量与判断逻辑规范 V1.0

## 1. 文档目的

本文档用于复查当前选股程序的实现是否符合交易逻辑。

当前三个池的定义正式统一为：

- **A池：趋势反转候选**
  - 原状态：长期下降趋势
  - 寻找：长期下降可能正在结束，并出现初步向上变化

- **B池：趋势中继候选**
  - 原状态：已经形成上涨趋势
  - 寻找：上涨趋势中的正常调整，以及调整后的重新转强

- **C池：下降趋势中的反弹候选**
  - 原状态：下降趋势仍然存在
  - 寻找：短期下跌较充分后发生阶段性向上反弹
  - 不要求长期下降趋势已经结束

三个池回答的是三个完全不同的问题：

A：

> 原来的下降趋势是不是可能结束？

B：

> 原来的上涨趋势是不是仍然活着？

C：

> 原来的下降趋势虽然还活着，但短期是不是可能反弹？

---

# 2. 总体实现原则

程序采用：

**硬条件 + 评分条件 + 阶段判断**

三层结构。

不能把几十个指标全部写成硬条件。

硬条件只用于证明：

> 这只股票在逻辑上属于这一类机会。

评分条件用于判断：

> 它有多像这一类机会。

---

# 3. 数据周期

核心选股周期：

**日线**

长期背景：

使用最近：

120 / 250 / 500

个交易日。

其中：

- 20日 ≈ 1个月
- 60日 ≈ 1季度
- 120日 ≈ 半年
- 250日 ≈ 1年
- 500日 ≈ 2年

周线由日线本地聚合。

周线只作为：

长期趋势辅助判断。

不能因为周线指标暂未生成导致整个池无法工作。

## 5.2 均线斜率

定义：

ma20_slope_10 =
MA20(t) / MA20(t-10) - 1

ma60_slope_20 =
MA60(t) / MA60(t-20) - 1

ma120_slope_20 =
MA120(t) / MA120(t-20) - 1

ma120_slope_60 =
MA120(t) / MA120(t-60) - 1

不要简单用：

MA60今天 > MA60昨天

判断趋势。

ret_5

ret_10

ret_20

ret_60

ret_120

ret_250

公式：

ret_N =
close(t) / close(t-N) - 1

# 7. 高低点变量

计算：

prev_high_20

prev_high_60

prev_high_120

prev_high_250

prev_low_20

prev_low_60

prev_low_120

prev_low_250

注意：

**必须使用t-1以前的数据。**

例如：

prev_high_60(t)

只能使用：

t-60 ～ t-1

不能把今天的数据包含进去。

否则存在未来/自引用错误。

# 8. 距离阶段高低点

例如：

distance_high_120 =
close / prev_high_120 - 1

distance_low_120 =
close / prev_low_120 - 1

# 9. 回撤

定义：

drawdown_20 =
close / prev_high_20 - 1

drawdown_60 =
close / prev_high_60 - 1

drawdown_120 =
close / prev_high_120 - 1

drawdown_250 =
close / prev_high_250 - 1

均为负数表示回撤。

用于判断历史上是否经历过明显下降。

# 11. ATR

计算：

ATR14

以及：

atr_pct =
ATR14 / close

ATR主要解决：

不同股票波动率不同的问题。

例如：

10%的回调

对于低波动股票可能非常大，

对于高波动股票可能很普通。

# 15. 波动率

计算：

volatility_20

以及：

volatility_prev20

定义：

volatility_contract =
volatility_20 / volatility_prev20

小于1：

近期波动有所收缩。

# 16. Swing High / Swing Low

需要实现基础波段高低点识别。

建议：

pivot_window = 5

某日i：

如果：

high[i]

是：

i-5 ～ i+5

区间最高值，

则确认：

Swing High。

类似定义：

Swing Low。

注意：

Swing点只有经过后面5个交易日以后才能确认。

历史扫描中：

不得提前知道尚未确认的Swing。

**长期下降趋势后的潜在反转。**

必须先证明：

> 过去确实存在持续下降趋势。

# 37. B池定义

寻找：

**原来存在可靠上涨趋势，现在发生正常调整，趋势结构没有明显破坏，并可能重新转强。**

逻辑顺序必须严格：

1. 先证明原上涨趋势存在
2. 再证明当前正在调整
3. 再判断调整是否健康
4. 最后判断是否企稳/转强

不能直接：

跌到MA20或MA60

就进入B池。

# 69. C池定义

C池寻找：

**下降趋势仍然存在，但是短期跌得较充分以后出现反弹机会。**

它与A池最关键的区别：

A：

寻找长期趋势改变。

C：

不要求长期趋势改变。

因此C的预期持有周期通常应比A/B更短。

# 106. 当前版本的重要原则

V1追求：

**类型正确**

而不是：

**预测正确。**

例如：

一个A池股票后来继续下跌，

并不意味着筛选错误。

只要当时它确实属于：

“长期下降以后出现值得研究的反转迹象”，

A池就完成了职责。

同理：

B池不是保证中继成功。

C池也不是保证反弹持续。

程序负责：

识别交易情景。

最终是否值得承担风险，

仍然需要后续人工研究和交易计划。
