# 交易系统交易总览 UI 颜色与标签参考 V1.0

## 目的

交易总览沿用项目自动选股页面已经使用的浅色标签体系。颜色只表达业务状态，不用于装饰或替代文字说明。

## 可复用颜色

| 语义 | 背景 | 文字 | 边框 | 使用场景 |
| --- | --- | --- | --- | --- |
| 正向 / 已完成 | `bg-emerald-50` | `text-emerald-800` | `border-emerald-200` | 已连接、运行中、已完成、数据正常 |
| 风险 / 亏损 | `bg-rose-50` | `text-rose-800` | `border-rose-200` | 风险、亏损、拒单、异常 |
| 提醒 / 处理中 | `bg-amber-50` | `text-amber-900` | `border-amber-200` | 清仓中、待处理、需要复核 |
| 信息 / 处理中性状态 | `bg-sky-50` | `text-sky-800` | `border-sky-200` | 计划中、说明性状态 |
| 主题 / 策略分类 | `bg-violet-50` | `text-violet-800` | `border-violet-200` | 交易类型、策略来源、主题标签 |
| 中性 / 未记录 | `bg-slate-100` | `text-slate-700` | `border-slate-200` | 未关联、暂无数据、已结束 |

## 交易总览卡片

顶部指标卡片可以使用同一套浅色背景，但必须通过左侧强调边框和图标颜色区分语义：

- 账户净资产：绿色系，代表账户基础资产。
- 可用现金：天空蓝系，代表流动性信息。
- 当前总仓位：琥珀色，代表资金占用和限制提醒。
- 账户当前总计划风险：玫红色，代表风险预算和风险暴露。

卡片内容仍以 API 返回值为准，颜色不改变数据含义。

## 列表标签

- 交易类型使用标签：趋势交易使用蓝色，反弹 / 波段使用紫色，固定目标使用琥珀色，自定义或未记录使用灰色。
- Trade 状态使用标签：进行中使用绿色，计划中使用蓝色，清仓中或已暂停使用琥珀色，已结束使用灰色。
- 最近动作使用琥珀色标签；没有动作时使用中性灰色标签。

## 红涨绿跌行背景

交易总览保留“红涨绿跌模式”标识，并按当前价与买入价对整行着色：

- 当前价高于买入价：整行浅红色，表示盈利。
- 当前价低于买入价：整行浅绿色，表示亏损。
- 两个价格缺失或相等：不着色，避免把未知或无变化误判成涨跌。

这是 A 股展示约定，不影响后端计算和交易判断。
