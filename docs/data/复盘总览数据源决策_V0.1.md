# 复盘总览数据源决策

**版本：** V0.2  
**验证日期：** 2026-08-03  
**原验证脚本：** `scripts/validate_akshare_data.py`  
**当前验证入口：** `data_source_validation/run_validation.py`
**原验证报告：** `docs/data/akshare_validation_report.md`

---

# 1. 总体结论

当前数据源方向调整为 TuShare 优先策略。

本次验证发现：

1. 东方财富相关 AkShare 接口在当前环境存在连接失败风险；
2. 乐咕市场活跃度接口返回异常，不适合作为首版核心依赖；
3. 腾讯指数历史接口、同花顺行业接口、新浪全市场快照、中证指数成分权重接口可用；
4. 本项目 `.env` 已独立配置 `TUSHARE_TOKEN`，并验证 2200 积分可调用 `daily`、`adj_factor` 和 `index_weight`；
5. Tushare 当前 token 无 `ths_index`、`ths_daily`、`sw_daily`、`limit_list_d` 权限。

首版采用“字段级明确数据源 + 缺失即报错/标记缺失”的方式，不做运行时隐性兜底。

数据源优先级原则：

1. TuShare 已验证可用的核心字段优先使用 TuShare；
2. AkShare 仅作为 TuShare 缺失数据、无权限数据和交叉核对的补充源；
3. 不做运行时隐性兜底，字段采集失败必须报错或标记缺失；
4. 如需改变某个字段的数据源，先修改本口径文档并确认。

# 3. 产品口径调整

## 3.1 行业口径

原需求文档写“申万一级行业”。

首版实际采用：

> AkShare 同花顺行业板块。

原因：

1. 同花顺行业板块接口当前验证可用；
2. 能直接提供行业涨跌幅、成交额、上涨家数、下跌家数；
3. 不需要自建行业成分聚合；
4. 更符合首版快速落地目标。

界面和报告必须显示“行业口径：同花顺行业板块”，不能写成申万一级行业。

## 3.2 市场广度口径

当日市场广度由 `stock_zh_a_spot` 快照计算：

- 上涨家数：`涨跌幅 > 0`
- 下跌家数：`涨跌幅 < 0`
- 平盘家数：`涨跌幅 = 0`
- 上涨比例：上涨家数 / 有效股票数量
- 全市场成交额：快照 `成交额` 求和

这属于明确计算口径，不是兜底。

历史与技术广度使用落库的 60 个交易日 Tushare 数据：

- 每日上涨、下跌、平盘家数及成交额：`daily`；
- 创 20 日新高/新低：`daily.close * adj_factor` 的复权收盘价；
- 站上 20/60 日线：基于同一复权收盘价序列计算。

首次生成回填 60 个交易日，后续只采集数据库中缺失的交易日。不满 60 个交易日或复权因子缺失时，报告生成直接报错。

## 3.3 涨跌停口径

涨停家数直接使用 `stock_zt_pool_em(date)` 返回行数。

跌停家数直接使用 `stock_zt_pool_dtgc_em(date)` 返回行数。若接口返回空表且无字段，无法区分真实 0 家与接口异常，本次报告生成直接报错，不写入“未知”或“缺失”。

首版不使用 Tushare `limit_list_d`，也不从个股涨跌幅自行推算涨跌停。

## 3.4 指数关键成分股口径

界面不再展示估算贡献、成分覆盖率和权重日期等数据工程指标。指数卡片按指数当日方向筛选关键成分股：

- 指数下跌：展示当日跌幅最大的 5 只成分股；
- 指数上涨：展示当日涨幅最大的 5 只成分股；
- 每只股票展示名称、当日涨跌幅和同花顺公司页提供的所属申万行业。

当前数据源为：

- 沪深300、中证500、中证1000、科创50：AkShare 中证指数权重；
- 创业板指：Tushare `index_weight`；
- 五个指数的成分股当日收益：Tushare `daily` 全市场单日批量行情。

权重仅用于确认报告日的指数成分范围，不在复盘界面解释为个股贡献。关键成分股行业映射按交易日保存并复用；名称或行业缺失时报告生成直接报错。

# 4. 哪些数据直接取，哪些需要计算

## 4.1 直接取

- 指数日线开高低收；
- 指数成交字段 `amount`；
- 行业当日涨跌幅；
- 行业总成交额；
- 行业上涨家数、下跌家数；
- 涨停池列表；
- 跌停池列表；
- 中证指数成分与权重。

## 4.2 派生计算

- 指数 1周、5周、20周、60周收益；
- 周线 20周、30周、60周均线状态；
- 阶段高点回撤；
- 指数相对强弱排序；
- 指数成交额相对 20周均值；
- 上涨比例；
- 指数与市场广度四象限；
- 行业 5日、20日、60日收益；
- 行业排名变化；
- 行业内部上涨比例；
- 当日涨幅前 10 和跌幅前 10 的行业排名；
- 全市场创 20 日新高/新低家数与比例；
- 全市场站上 20/60 日线的家数与比例；
- 风格和风险偏好自动解释。

# 5. 实现约束

1. 数据采集失败时，不能换接口继续生成同一字段。
2. 字段缺失时，该字段状态为缺失，自动结论不得引用。
3. 所有接口和阈值集中配置。
4. 页面不直接请求 AkShare；由后端采集、入库、计算后提供结果。
5. 每次复盘保存原始数据快照、计算结果和自动结论证据。
6. Tushare 优先用于已确认的 `daily`、`adj_factor`、`daily_basic`、`trade_cal` 和可用指数/ETF字段；AkShare 用于补充缺口与交叉核对。
7. `TUSHARE_TOKEN` 只从本项目环境读取，缺失时归因生成直接报错。
