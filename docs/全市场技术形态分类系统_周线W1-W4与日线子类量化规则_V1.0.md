# 全市场技术形态分类系统设计与量化规则 V1.0

> 用途：交给 AI Coder 直接实现，并作为后续全市场分类、选股扫描和策略研究的共同技术底座。
>
> 核心思想：**周线 W1~W4 负责大背景，日线子类负责当前技术结构。**
>
> 周线采用 Stan Weinstein Stage Analysis 的四阶段思想作为骨架；文中的具体数值阈值是本系统为了量化落地设计的 V1 参数，不是 Weinstein 原文中的固定标准。

---

# 1. 最终数据模型

每只股票、每个交易日只输出：

```text
weekly_stage       # W1 / W2 / W3 / W4
daily_subtype      # 当前 W 下唯一一个日线子类
subtype_family
setup_score        # 仅机会型子类计算
score_type
is_overextended
episode_fields
reason_codes
classifier_version
```

例如：

```text
weekly_stage = W4_DECLINE
daily_subtype = W4_EARLY_PREP
setup_score = 72
```

表示：

> 周线仍处于下跌背景，但日线已经进入早期修复准备。

周线是慢变量，因此完全允许：

```text
W4 下跌
+
日线已经第一波上涨 / 第一波回调 / 二次转强
```

这不矛盾。系统只描述已经发生的事实，不提前断言日线反弹最终是否会变成周线反转。

# 2. 数据与公共指标

## 2.1 数据

沿用当前系统：

- 前复权日 K；
- Point-in-Time；
- 建议读取至少 250 根日 K；
- 日线聚合周 K；
- W1~W4 只使用**已经完成的周 K**；
- 周中评估时，不能拿本周未来几天的数据补齐周线；
- 少于 35 根完整周 K 时，`weekly_stage_unavailable=true`，不要伪造 W1~W4。

## 2.2 周线指标

```text
WMA30 = 周收盘 SMA30

wma30_slope_5w
= WMA30(t) / WMA30(t-5) - 1

weekly_dist_ma30
= weekly_close / WMA30 - 1

weekly_ret_13w
weekly_ret_26w

weekly_range_pos_52w
= (close - low_52w) / (high_52w - low_52w)
```

## 2.3 日线指标

继续使用：

```text
MA5 / MA10 / MA20 / MA30 / MA60
ATR20
retake_count
order_score
cross_pair_count_10d
cross_event_count_10d
volume_ratio
extension_atr
```

新增：

```text
return_5d / 10d / 20d / 40d
drawdown_20d / 40d / 60d
days_from_40d_high

ma5_slope_5d
ma10_slope_5d
ma20_slope_5d
ma30_slope_5d
ma60_slope_20d

ma10_slope_prev5
ma20_slope_prev5

ma10_curve_improve
= ma10_slope_5d - ma10_slope_prev5

ma20_curve_improve
= ma20_slope_5d - ma20_slope_prev5
```

统一：

```text
maX_slope_5d = MA_X(t) / MA_X(t-5) - 1
```

所谓“均线画弧”，V1 不做复杂曲线拟合，而用：

> 前 5 日下降较快 → 最近 5 日下降明显减速 → 接近走平/转正

来量化。

## 2.4 均线压缩

必须真实计算：

```text
ma_spread_now
ma_spread_5d_ago
```

不要再用 `当前 spread * 1.2` 代替五日前数据。

```text
ma_spread_atr
=
(max(MA5, MA10, MA20, MA30)
 - min(MA5, MA10, MA20, MA30))
/ ATR20

spread_contract_ratio
= ma_spread_now / ma_spread_5d_ago
```

# 3. 周线 W1~W4 量化规则

## W2_ADVANCE

普通候选：

```text
wma30_slope_5w >= +1.5%
AND
weekly_close >= WMA30 * 1.02
```

连续 2 个完整周满足后确认。

极强条件：

```text
wma30_slope_5w >= +2.5%
AND
weekly_close >= WMA30 * 1.05
```

可当周确认。

## W4_DECLINE

普通候选：

```text
wma30_slope_5w <= -1.5%
AND
weekly_close <= WMA30 * 0.98
```

连续 2 周确认。

极强条件：

```text
wma30_slope_5w <= -2.5%
AND
weekly_close <= WMA30 * 0.95
```

可当周确认。

## W1_BASE / W3_TOP

当：

```text
abs(wma30_slope_5w) < 1.5%
```

或价格长期围绕 WMA30 震荡时，进入横向阶段候选。

区分 W1/W3 必须看**前一个明确周线阶段**：

```text
最近一个明确阶段是 W4
→ W1_BASE

最近一个明确阶段是 W2
→ W3_TOP
```

这是必须保存的状态记忆。

初始化历史时若没有前一阶段：

```text
weekly_ret_26w <= -10%
或 weekly_range_pos_52w <= 0.45
→ W1

weekly_ret_26w >= +10%
或 weekly_range_pos_52w >= 0.55
→ W3

其余：
weekly_ret_26w < 0 → W1
weekly_ret_26w >=0 → W3
```

只用于首次初始化，正常运行后优先使用前一阶段。

# 4. 日线共用概念

## 4.1 “日线下跌充分”

用于识别真正经历过一段下跌，而不是跌 2~3 天：

```text
days_from_40d_high >= 8
AND
满足任一：

return_20d <= -8%
return_40d <= -15%
drawdown_60d >= 18%
```

## 4.2 “均线开始画弧”

以下至少满足 2 项：

```text
ma10_slope_5d >= -1.0%
ma20_slope_5d >= -1.5%
ma10_curve_improve >= +0.8%
ma20_curve_improve >= +0.8%
```

## 4.3 “均线开始靠拢/交叉”

满足任一：

```text
ma_spread_atr <= 1.20
spread_contract_ratio <= 0.85
cross_pair_count_10d >= 1
```

重要原则：

> **“还没 FIRST_TURN”不等于“EARLY_PREP”。**

EARLY_PREP 必须真正出现：

> 下跌/调整充分 + 均线减速走平 + 靠拢/交叉 + K 线开始夺回短均线。


# 5. W4_DECLINE 下的日线子类

W4 是原 A-Pre 最核心的背景。

子类：

```text
W4_DECLINE
W4_ACCEL_DECLINE
W4_DECLINE_DECELERATING
W4_EARLY_PREP
W4_FIRST_TURN
W4_FIRST_ADVANCE
W4_FIRST_PULLBACK
W4_SECOND_TURN
W4_MATURE_REBOUND
```

## 5.1 W4_ACCEL_DECLINE

满足：

```text
return_5d <= -8%
OR return_10d <= -12%
```

同时：

```text
close < MA20
AND
ma20_slope_5d <= -2%
```

含义：下跌正在加速，不属于早期转强。

## 5.2 W4_DECLINE_DECELERATING

必须先满足：

```text
日线下跌充分
```

然后：

```text
ma10_curve_improve >= +0.8%
OR ma20_curve_improve >= +0.8%
```

但还未达到 EARLY_PREP。

含义：跌速已经减慢，但结构还没有真正开始转变。

## 5.3 W4_EARLY_PREP

必须：

```text
日线下跌充分 = true
```

并同时满足：

### 均线弧度
“均线开始画弧”至少 2 项。

### 均线靠拢
满足任一：

```text
ma_spread_atr <= 1.20
spread_contract_ratio <= 0.85
cross_pair_count_10d >= 1
```

### 价格开始夺回
```text
retake_count >= 1
```

`retake_count >= 2` 只提高准备度，不是硬门槛。

### 仍不能已经是 FIRST_TURN
```text
NOT W4_FIRST_TURN
```

### 不能已经明显拉远
```text
extension_atr <= 1.5
```

这就是当前用户所说的：

> 日线经历一段较充分下跌后，短均线逐渐形成较大的弧度、走平、靠拢或交叉，K 线开始站回短均线。

Freshness **不参与这个状态的核心判断**。

## 5.4 W4_FIRST_TURN

触发：

```text
retake_count >= 3
AND
order_score >= 2
AND
MA5 > MA10
AND
(
    ma_spread_atr <= 1.20
    OR cross_pair_count_10d >= 2
)
```

进入时固定记录：

```text
episode_base_low
episode_base_low_date
first_turn_date
first_turn_close
first_turn_atr
```

`episode_base_low` 取：

> 进入本轮 DECLINE_DECELERATING / EARLY_PREP 前后最近 40 日最低价。

一旦 Episode 建立，本轮内不能漂移。

## 5.5 W4_FIRST_ADVANCE

首次转强后至少 2 个交易日，并且从本轮底部到阶段高点满足任一：

```text
max_close_since_base / episode_base_low - 1 >= 8%

或

(max_high_since_base - episode_base_low) / ATR_at_base >= 2.5
```

同时：

```text
drawdown_from_first_wave_high < 5%
```

则：

```text
W4_FIRST_ADVANCE
```

第一波必须从 `episode_base_low` 看，不只从触发价看。

## 5.6 W4_FIRST_PULLBACK

必须历史上已真实出现 FIRST_ADVANCE。

随后：

```text
drawdown_from_first_wave_high >= 5%
```

且：

```text
close > episode_base_low * 1.03
```

则：

```text
W4_FIRST_PULLBACK
```

它表示：

> 第一段上涨已经发生，现在进入第一次有意义的回调。

## 5.7 W4_SECOND_TURN

必须已有 FIRST_PULLBACK。

随后：

```text
retake_count >= 2
AND
ma5_slope_5d > 0
AND
close >= MA5
AND
close / pullback_low - 1 >= 4%
```

并满足任一：

```text
cross_pair_count_10d >= 1

close > MA20

close > 前5日最高收盘价
```

则：

```text
W4_SECOND_TURN
```

这里**不强制 MA5 > MA10**，因为第二波刚启动时 MA10 可能仍滞后。

## 5.8 W4_MATURE_REBOUND

已经有 SECOND_TURN 后，满足任一：

```text
close > first_wave_high_close

或

ma20_slope_5d > 0
AND
return_10d >= 10%
```

则：

```text
W4_MATURE_REBOUND
```

表示：

> 日线已经进入多波/成熟反弹，甚至可能正在向周线反转演化，但周线慢变量暂时仍是 W4。

## 5.9 W4_DECLINE

以上都不满足时：

```text
W4_DECLINE
```

表示当前仍主要是下降结构。

# 6. W1_BASE 下的日线子类

子类：

```text
W1_BASE_RANGE
W1_BASE_COMPRESSION
W1_EARLY_PREP
W1_FIRST_TURN
W1_BREAKOUT
W1_BREAKOUT_PULLBACK
W1_BREAKOUT_REACCEL
W1_FAILED_BREAKOUT
```

## W1_BASE_RANGE

默认状态：周线已筑底，但日线没有更明确的压缩、转强或突破信号。

## W1_BASE_COMPRESSION

```text
ma_spread_atr <= 0.80
AND
20日价格振幅 <= 12%
AND
cross_pair_count_10d >= 2
```

其中：

```text
20日价格振幅
= (HH20 - LL20) / ((HH20 + LL20) / 2)
```

## W1_EARLY_PREP

先满足任一：

```text
drawdown_20d >= 5%
60日区间位置 <= 0.60
```

再满足：

```text
均线开始画弧 >= 2项
AND
(
    ma_spread_atr <= 1.20
    OR cross_pair_count_10d >= 1
)
AND
retake_count >= 1
AND
extension_atr <= 1.5
```

且尚未达到 W1_FIRST_TURN。

## W1_FIRST_TURN

```text
retake_count >= 3
AND
order_score >= 2
AND
MA5 > MA10
AND
(
    ma_spread_atr <= 1.20
    OR cross_pair_count_10d >= 2
)
```

业务含义：

> 周线筑底区里的一次日线有效启动。

## W1_BREAKOUT

```text
base_upper = 过去60日最高收盘价（不含当前日）
```

满足任一：

```text
close >= base_upper * 1.01
AND volume_ratio >= 1.20
```

或：

```text
连续2日 close > base_upper
```

记录：

```text
breakout_date
breakout_level
```

## W1_BREAKOUT_PULLBACK

已有 BREAKOUT，之后：

```text
drawdown_from_breakout_high >= 4%
AND
close >= breakout_level * 0.97
AND
close <= breakout_level * 1.05
```

## W1_BREAKOUT_REACCEL

已有 BREAKOUT_PULLBACK：

```text
retake_count >= 3
AND
ma5_slope_5d > 0
AND
close >= breakout_level
AND
close > 前5日最高收盘价
```

## W1_FAILED_BREAKOUT

已有突破事件，满足任一：

```text
连续2日 close < breakout_level * 0.97
```

或：

```text
close < MA30
AND
close < breakout_level * 0.97
```

则判突破失败，但周线不因此立即强制变成 W4。


# 7. W2_ADVANCE 下的日线子类

子类：

```text
W2_STEADY_ADVANCE
W2_ACCEL_EXTENDED
W2_PULLBACK
W2_PULLBACK_STABILIZING
W2_REACCEL
W2_TREND_DAMAGE
```

## W2_STEADY_ADVANCE

默认状态。

典型：

```text
close >= MA20
MA20 大体向上
没有明显延伸
没有趋势破坏
```

## W2_ACCEL_EXTENDED

满足任一：

```text
return_10d >= 15%

extension_atr > 2.5

close / MA20 - 1 >= 15%
```

表示趋势仍强，但当前位置已经明显拉远。

## W2_PULLBACK

```text
drawdown_20d >= 4%
```

并满足任一：

```text
close < MA10
return_10d < 0
```

同时：

```text
close >= MA60 * 0.97
```

表示上涨趋势中的正常调整。

## W2_PULLBACK_STABILIZING

必须先有：

```text
drawdown_20d >= 6%
AND
距离20日高点至少5个交易日
```

随后：

```text
均线开始画弧 >= 2项
AND
retake_count >= 1
AND
(
    ma_spread_atr <= 1.20
    OR cross_pair_count_10d >= 1
)
```

表示：

> 周线上涨背景里，日线一次比较充分的调整开始企稳。

它的图形可以与 W4_EARLY_PREP 很像，但交易背景完全不同。

## W2_REACCEL

已有 PULLBACK 或 PULLBACK_STABILIZING：

```text
retake_count >= 3
AND
ma5_slope_5d > 0
AND
close > MA20
AND
close > 前5日最高收盘价
```

则：

```text
W2_REACCEL
```

这是未来 B 池最值得读取的状态之一。

## W2_TREND_DAMAGE

```text
close < MA60 * 0.97
```

并满足任一：

```text
drawdown_60d >= 20%

ma20_slope_5d <= -2%
```

则：

```text
W2_TREND_DAMAGE
```

周线因为滞后可能仍是 W2，但日线已经明确发生结构破坏。

# 8. W3_TOP 下的日线子类

W3 不直接等于“马上见顶下跌”。

它只是：

> 上涨后的周线均线已经趋平，趋势不再像 W2 那样顺畅。

子类：

```text
W3_HIGH_RANGE
W3_HIGH_COMPRESSION
W3_HIGH_REPAIR
W3_HIGH_REACCEL
W3_HIGH_WEAKENING
W3_BREAKDOWN
W3_POST_BREAKDOWN_REBOUND
```

## W3_HIGH_RANGE

默认高位震荡状态。

## W3_HIGH_COMPRESSION

```text
20日价格振幅 <= 10%
AND
ma_spread_atr <= 0.80
AND
60日区间位置 >= 0.55
```

分类只说明高位收敛，不预测向上还是向下。

## W3_HIGH_REPAIR

先有：

```text
drawdown_20d >= 6%
```

然后：

```text
均线开始画弧 >= 2项
AND
retake_count >= 1
AND
(
    ma_spread_atr <= 1.20
    OR cross_pair_count_10d >= 1
)
```

表示高位/趋势衰减背景中的一次日线修复准备。

## W3_HIGH_REACCEL

已有 HIGH_REPAIR 或高位调整：

```text
retake_count >= 3
AND
ma5_slope_5d > 0
AND
close > MA20
AND
close > 前5日最高收盘价
```

则：

```text
W3_HIGH_REACCEL
```

如果后续周线重新转强，W3 可以重新迁移到 W2。

## W3_HIGH_WEAKENING

```text
drawdown_20d >= 8%
AND
close < MA20
AND
MA5 < MA10
AND
ma20_slope_5d <= 0
```

但还没满足明确 BREAKDOWN。

## W3_BREAKDOWN

满足任一：

```text
close < MA60 * 0.98
AND
drawdown_60d >= 15%
```

或：

```text
close < 过去40日最低收盘价 * 0.98
```

记录：

```text
breakdown_date
breakdown_level
```

## W3_POST_BREAKDOWN_REBOUND

已有 BREAKDOWN：

```text
close > MA5
AND
return_5d > 0
```

但：

```text
close < MA30
OR
close < MA60
```

则表示高位破位后的反抽，而不是重新进入真正上涨趋势。

# 9. Episode 规则

只有需要先后关系的链条保存 Episode：

```text
W4 下跌→转强
W1 突破→回踩→再启动
W2 回调→企稳→再启动
W3 破位→反抽
```

## 9.1 W4 Turn Episode 保存

```text
episode_base_low
episode_base_low_date

first_turn_date
first_turn_close

first_wave_high_close
first_wave_high_date

pullback_low
pullback_low_date
```

必须满足：

- base low 一旦确定，在本轮里固定；
- first_turn 只记录第一次正式触发；
- 第一波优先从 base low 到高点判断；
- 第一波已经形成以后，不允许重新回 EARLY_PREP / FIRST_TURN；
- 只能进入 FIRST_PULLBACK / SECOND_TURN / MATURE_REBOUND，或整轮真正失败。

## 9.2 W4 Episode 真正失败

如果历史上还**没有**形成 FIRST_ADVANCE：

满足任一：

```text
close < episode_base_low * 0.98
```

或：

```text
出现新的60日低点
AND
MA20/MA30继续明显向下
```

则结束旧 Episode，回到：

```text
W4_DECLINE
或
W4_DECLINE_DECELERATING
```

不要把失败直接重新叫 EARLY_PREP。

## 9.3 已经有第一波以后

一旦历史上达到 FIRST_ADVANCE：

```text
禁止回：
W4_EARLY_PREP
W4_FIRST_TURN
```

除非以后出现真正新的低点和新一轮结构重置。

# 11. 评分：分类与评分分开

不要再给所有状态强行打一把统一的 100 分。

V1 只对“值得排序”的机会型状态计算 `setup_score`。

---

## 11.1 PREP_SCORE

适用于：

```text
W4_EARLY_PREP
```

# 20. 最终原则

> **周线阶段描述大背景，不预测日线反弹最终是不是周线反转。**

> **日线子类描述已经发生的结构，而不是把所有股票硬塞进“准备 / 首次 / 已完成”三个桶。**

> **同样的日线早期修复可以出现在 W4、W1、W2、W3，但交易含义不同。**

> **分类先于策略；策略只是从分类结果里挑自己真正负责的机会。**

# 21. 参考框架说明

周线 W1~W4 的思想采用 Stan Weinstein Stage Analysis：

- 使用周线观察；
- 30 周均线是核心工具；
- Stage 2 对应 advancing；
- Stage 4 对应 declining；
- Stage 1 / Stage 3 都可能表现为均线走平和横向阶段，前一阶段是区分二者的重要依据。

本文件中的：

```text
±1.5% 周线斜率
±2% 与30周均线距离
2周确认
所有日线 subtype
所有日线阈值
```

均为本系统为了程序化落地制定的 V1 规则，不是 Weinstein 理论中的固定原文参数。

后续必须用 A 股历史样本和全市场实际分布迭代，而不是把这些数值视为市场定律。
