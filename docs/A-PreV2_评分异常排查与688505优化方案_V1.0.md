# A-Pre V2 评分异常排查与复旦张江 688505 优化方案 V1.0

> 用途：交给 AI Coder 直接执行排查与修改  
> 目标：确认 A-Pre V2 当前评分是否存在重复计分、过度奖励“已经上涨”、缺少“转向新鲜度/上方压力/二次转强识别”等问题，并以 **复旦张江 688505.SH，2026-08-10** 作为首个回归样本。  
> 注意：**先排查、后改规则**。不要为了让 688505 从 93 分降下来而直接拍脑袋改权重。

## 1. 背景

A-Pre V2 的目标不是寻找“已经明显上涨的强势股”，而是尽量提前发现：

1. 原有下跌/调整趋势正在失去控制；
2. MA5/MA10/MA20/MA30 等短中期均线由分散转为压缩、交叉、重新排序；
3. 股价刚刚夺回短中期成本区；
4. 短周期均线率先向上，较长周期均线开始改善；
5. 当前价格仍离均线团较近，尚未明显延伸；
6. 最好是在“转向刚发生”的早期阶段，而不是已经连续转强很多天。

当前系统在 `2026-08-10` 选出：

- `688505.SH 复旦张江`
- 得分约 `93`

人工复核认为：

- **选出来是合理的**
- **但 93 分明显偏高**
- 更像“值得进入观察/早期转强名单”的中上等样本
- 不像接近满分的典型“首次、早期、空间优良”的转向样本

因此需要排查当前评分结构。

# 2. 本次排查的核心问题

按优先级检查以下 6 类问题。

## P0-1：是否存在高度相关指标重复计分

重点检查下面这些信号是否分别拿了大量分数：

- `close > MA5/10/20/30`
- `retake_count`
- `MA5 slope > 0`
- `MA10 slope > 0`
- `up_slope_count`
- `MA cross count`
- `directional_cross`
- `MA order improvement`
- `MA compression`
- `MA knot`
- `price above MA cluster`

这些指标很多可能来自同一个底层事实：

> 最近几天股价上涨，使短均线上拐并发生交叉。

如果每个指标都独立高分，就会形成：

> 一次短期上涨 → 同时触发 6~8 个指标 → 分数瞬间冲到 90+

### 要求

输出当前评分公式的完整拆解：

```text
total_score
  = module_a
  + module_b
  + module_c
  ...
```

并进一步打印每个子指标：

```text
feature_name
raw_value
normalized_value
score
max_score
reason
```

必须能够看到 688505 的 93 分到底由哪些项组成。

---

## P0-2：是否把“现在很强”误当成“刚刚转强”

A-Pre V2 的核心应包含 **Earliness / 转向新鲜度**。

检查当前系统是否出现：

- 已连续站上 3~4 根均线很多天，仍拿满分；
- MA5/MA10 已向上多日，仍按“刚转向”计分；
- 交叉发生在较早日期，但今天仍重复拿“MA Knot / directional cross”高分；
- 当前只是第二次反弹/二次启动，却被当作第一次底部转向。

### 必须新增/核查的时间变量

至少计算：

```text
days_since_first_retake_3ma
days_since_first_retake_4ma
days_since_ma5_slope_positive
days_since_ma10_slope_positive
days_since_last_ma_knot
days_since_directional_cross
days_since_local_low
```

这些变量先用于诊断，不要求马上全部进入评分。

---

## P0-3：是否缺少“首次转向 vs 二次转强”分类

复旦张江 2026-08-10 并不是非常典型的“第一次从底部刚刚转向”。

从图形上更接近：

```text
6月附近低点
→ 已有一轮反弹到 7.8~8.0 附近
→ 再次回落到 7.1 左右
→ 8月重新转强
```

因此应识别：

- `FIRST_TURN`：首次从长期弱势/底部转向
- `SECONDARY_TURN`：底部第一次反弹后回调，再次转强
- `CONSOLIDATION_RESTART`：原上涨趋势中的整理后再启动

### 初版诊断逻辑

不要先做硬过滤，只做标签：

```text
if 最近60日内已经出现过：
    close > MA5, MA10, MA20 至少连续N天
and 此后又重新跌回均线团/MA20附近
and 当前再次满足 retake:
    secondary_turn = true
```

先用：

```text
N = 3
lookback = 40~60 trading days
```

# 5. “三角形/四边形”优化：不要只统计交叉次数

当前如果只是：

```text
cross_pair_count >= 2 or 3
```

会把大量无方向横盘股票打高分。

必须同时考虑：

## 5.1 交叉前的旧状态

例如下降型：

```text
过去10~30日中曾较稳定出现：
MA5 < MA10 < MA20
```

或者：

```text
MA20 slope < 0
```

## 5.2 均线先收敛

定义：

```text
spread_t =
(max(MA5,MA10,MA20) - min(MA5,MA10,MA20)) / ATR20
```

以及：

```text
compression_ratio =
spread_today / spread_10d_ago
```

真正值得奖励的是：

```text
过去明显分散
→ 当前明显收敛
```

而不是一直横盘粘合。

## 5.3 交叉之后必须有方向

新增：

```text
directional_order_score
```

关注：

```text
MA5 > MA10
MA10 >= MA20 或正在快速接近
MA5 slope > 0
MA10 slope > 0
MA20 slope improving
```

核心：

> 交叉以后是否逐渐形成新的向上次序。

## 5.4 对“来回乱穿”设置惩罚

新增：

```text
cross_reversal_count
```

如果同一均线对在最近 10~15 日内：

```text
上穿
→ 下穿
→ 再上穿
```

次数过多，说明更像无方向震荡。

可以定义：

```text
chop_penalty
```

初版先只记录，不急着硬过滤。

# 7. 增加“上方压力/空间质量”

688505 的另一个问题：

> 2026-08-10 已接近过去多次发生价格反应的 7.8~8.2 区域。

当前评分如果完全不考虑上方空间，会把：

```text
刚转强 + 马上撞压力
```

和：

```text
刚转强 + 上方空间开阔
```

打成相近分数。

## 初版实现

计算：

```text
recent_high_60
recent_high_120
distance_to_high_60
distance_to_high_120
```

同时增加：

```text
overhead_resistance_flag
```

条件可综合：

- 当前价格上方 0~5% 内；
- 历史至少存在 2~3 次明显局部高点；
- 这些高点价格比较接近。

V1 先输出诊断，不急于成为硬过滤。

# 9. 成交量模块优化

不要简单：


```text

```


比单日突然巨量更适合 A-Pre。

688505 当前更适合：

```text
volume_confirmation = positive / medium
```

而不是：

```text

```

# 11. 禁止的修改方式

## 11.1 不要写 688505 特例

禁止：

```python
if ts_code == "688505.SH":
    score -= 20
```

## 11.2 不要整体乘系数

禁止：

```text
score = old_score * 0.8
```

这无法解决排序问题。

## 11.3 不要因为接近压力位直接 FAIL

A-Pre 是研究池，不是下单器。

压力位应：

```text
降优先级 / 标签
```

而不是默认淘汰。

## 11.4 不要要求 MA5 > MA10 > MA20 > MA30 全部完成

那会发现太晚。

V2 仍应允许：

```text
正在重排
```

的阶段入选。

# 17. 验收标准

1. 任意股票分数都可以完整解释到子指标；
2. 高度相关的均线指标不能无上限叠加；
3. 复旦张江 688505.SH 在 2026-08-10 仍应被识别为有效候选；

## 结论

本轮优化的核心不是“把 93 分降下来”，而是解决三个结构性问题：

```text
1. 同源信号重复计分

```

复旦张江只是用于暴露问题的首个样本，而不是模型要去拟合的唯一目标。
