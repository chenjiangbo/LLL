# 个人中期交易系统：后续设计与学习 To-Do List

**版本：** V0.1  
**更新时间：** 2026-08-02  
**目标：** 用约5年时间，逐步建立一套适合个人执行的A股中期交易体系。系统服务于实际交易，不追求一开始就做到机构级复杂度。

---

# 一、当前已经完成

## 第0步：交易边界与现实约束

已初步确定：

- 初始资金约10万元
- 主要交易A股主板、创业板个股和境内股票ETF
- 纳入科创板相关ETF，暂不直接交易科创板个股
- 第一阶段只做多，不做期货、期权、融资融券和日内交易
- 主要持有周期为数个交易日至数月
- 每晚可以投入时间研究，盘中只做有限观察和执行
- 排除ST、*ST、退市整理、次新、微盘和流动性明显不足的标的
- 账户权益按“现金＋持仓当前市值－负债及费用”计算
- 已设定第一版账户回撤控制框架，但后续仍需结合真实交易调整

## 第1步：统一思路与策略原型

已初步确定：

- 不追求提前预测终极大底或完整牛熊周期
- 统一思路是寻找价格状态从弱转强，或强势调整后重新转强的中期行情
- A池：长期弱势、低位区域中的基本面边际改善和价格转强
- B池：已有上升趋势、调整后可能重新转强
- 个股与ETF都是表达工具，不是独立策略
- 基本面、板块环境、资金线索和价格结构需要共同研究
- 市场环境用于理解机会和风险，不要求每天把市场精准贴入固定类别

---

# 二、当前正在进行

## 第2步：建立实际的市场观察能力

当前重点不是开发复杂市场分类模型，而是理解不同指数、行业和市场现象分别代表什么。

### 2.1 核心指数逐个研究

需要依次弄清：

- 沪深300代表哪些股票和资金风格
- 中证500代表什么
- 中证1000代表什么
- 创业板指代表什么
- 科创50代表什么
- 上证指数、深证成指是否还有辅助价值
- 不同指数强弱组合说明什么市场风格

每个指数都要完成：

- 月线长期结构判断
- 周线中期结构判断
- 日线当前阶段判断
- 当前结构对A池和B池选股有什么实际影响
- 不能从该指数推导出什么结论

### 2.2 市场广度与赚钱效应

需要弄清：

- 上涨家数和下跌家数反映什么
- 单日普涨或普跌的意义和局限
- 连续数日市场广度怎样观察
- 指数上涨但多数股票下跌说明什么
- 涨停、跌停、炸板和成交额分别能说明什么
- 市场情绪、市场趋势和市场赚钱效应的区别

### 2.3 行业、主题与风格

需要弄清：

- 行业板块、概念板块和风格指数的区别
- 怎样判断一个板块是持续走强还是一日脉冲
- 怎样区分板块趋势、轮动、补涨和退潮
- 板块内部龙头、跟随股和落后股怎样观察
- 行业趋势如何影响个股机会
- 个股强于行业、行业强于大盘分别说明什么

### 2.4 资金线索

需要弄清：

- 成交额增加或减少的不同含义
- ETF份额、成交额和资金净流入分别是什么
- 资金流入但价格下跌为什么可能同时发生
- 主力资金、北向资金、融资资金等数据的可靠性和局限
- 哪些资金数据只适合当线索，不能当买入依据

### 2.5 形成每日和每周市场观察记录

不要求强行判断牛熊，只需要持续回答：

- 当前哪些指数强、哪些弱
- 当前资金偏好哪种风格
- 哪些行业在持续增强
- 哪些行业在调整或退潮
- 市场对A池机会是否友好
- 市场对B池机会是否友好
- 当前交易难度是低、中还是高
- 哪些现象会推翻当前观察

# 三、后续交易系统设计任务

## 第3步：A池候选策略设计

需要确定：

- 什么叫长期弱势
- 什么叫大周期低位
- 什么叫抛压衰竭
- 什么叫基本面停止恶化或边际改善
- 什么叫价格开始转强
- 哪些底部结构可以观察
- 如何区分可交易反弹和完全没有确认的下跌中继
- 个股与行业ETF在A池中的使用条件
- A池候选进入、保留和删除规则

## 第4步：B池候选策略设计

需要确定：

- 什么叫已形成上升趋势
- 什么叫正常调整
- 什么叫趋势已经破坏
- 什么叫调整后重新转强
- 怎样判断高位但仍有趋势，还是趋势末端
- 怎样结合板块趋势、基本面和相对强度
- 个股与ETF在B池中的使用条件
- B池候选进入、保留和删除规则

## 第5步：基本面与行业研究框架

需要确定：

- A池和B池分别重点看哪些基本面信息
- 收入、利润、现金流、负债和盈利质量怎样使用
- 行业景气、库存、价格、政策和竞争格局怎样研究
- 如何识别价值陷阱
- 如何识别高增长但估值透支
- 公司公告、财报、新闻和机构观点如何交叉核实
- AI负责什么，人工必须判断什么
- 基本面研究最终怎样形成简短、可执行的结论

## 第6步：入场与交易计划

需要确定：

- 候选与可以买入之间的区别
- 开仓触发条件
- 突破买入、回踩买入或分批建仓的使用条件
- 什么叫追高
- 什么证据说明交易假设失效
- 技术止损应放在哪里
- 周线止损过宽时怎样处理
- 预期收益空间怎样估计
- 收益风险比不足时是否放弃
- 每笔交易前必须写清的交易计划

## 第7步：仓位与单笔风险

需要确定：

- 一笔交易最多允许亏账户的多少
- 止损越宽，仓位怎样缩小
- A股100股最小交易单位带来的限制
- 信号强弱是否以及怎样影响仓位
- 首次建仓、确认后加仓怎样分配
- 亏损仓位能否加仓
- 账户资金较小时怎样避免仓位过度分散

## 第8步：组合与总风险

需要确定：

- 同时最多持有多少只标的
- 单只股票和单个ETF的仓位上限
- 同一行业的持仓上限
- 不同股票实际上属于同一种风险时怎样处理
- A池与B池的风险暴露怎样观察
- 市场明显不利时怎样降低总仓位
- 现金在组合中的作用
- 账户回撤触发降仓、暂停和停机后怎样恢复交易

## 第9步：持仓管理与退出

需要确定：

- 买入后每天检查什么
- 原始买入逻辑是否仍然成立
- 初始止损、移动止损和结构止损的关系
- 盈利后何时提高止损
- 什么情况下加仓、减仓或全部退出
- 时间止损是否需要
- 大幅跳空、跌停和突发公告怎样处理
- 中期反弹如何避免过早卖出
- 趋势交易如何避免把利润全部坐回去

## 第10步：交易执行

需要确定：

- 下单前检查清单
- 限价单和市价相关委托怎样选择
- 高开、低开和快速波动时怎样执行
- 计划价格没有成交怎么办
- 滑点、佣金和印花税怎样记录
- 计划交易与冲动交易怎样区分
- T+1制度对开仓和止损的影响

## 第11步：自选池和工具使用流程

需要确定：

- 东方财富主要负责什么
- 同花顺主要负责什么
- 财联社、证券时报、新浪财经分别负责什么
- 是否只保留一个主要行情平台
- 指数、行业、A池、B池、计划交易和持仓怎样分组
- 每天怎样更新观察池
- 怎样避免重复阅读和信息过载
- 什么任务值得以后写小程序，什么任务直接人工完成

## 第12步：交易日志与复盘

需要确定：

- 每笔交易前记录什么
- 每笔交易后记录什么
- 看对没做、做了但执行错怎样记录
- 每日复盘、每周复盘和月度复盘分别做什么
- 技术判断错误、基本面错误、仓位错误和执行错误怎样分类
- 如何建立成功与失败案例库
- 如何从案例中形成“盘感”，而不是只凭印象

## 第13步：绩效与系统验证

需要确定：

- 胜率、平均盈利、平均亏损和盈亏比
- 期望值
- 最大回撤和连续亏损
- A池与B池分别表现如何
- 不同市场和行业环境下表现如何
- 规则是否有足够样本
- 参数是否过度拟合
- 什么时候需要历史回测
- 什么时候小资金实盘证据已经足够
- 什么证据说明应保留、修改或推翻策略

## 第14步：长期学习路线

需要持续进行：

- 学习市场结构、趋势、反转和波动
- 学习财务报表和行业研究
- 学习仓位、组合与风险管理
- 研究专业交易者的真实案例
- 研究A股制度、交易规则和市场参与者
- 每年总结自己的能力短板
- 逐步减少不适合自己的交易方式
- 最终形成少数真正熟练、可以重复执行的交易模式

# 四、当前暂时不做

为保证系统服务于交易，现阶段暂不优先开发：

- 复杂量化平台
- 自动交易
- 日内交易系统
- 实时行情系统
- 手机App和网页工作台
- 大型数据库
- 多策略自动组合
- AI自动给出买卖结论
- 十年全市场严谨回测
- 同时学习过多品种和策略

后续只有在真实使用中出现明确需求时，才增加工具或程序。

---

# 五、最近的执行顺序

当前建议按以下顺序继续：

1. 先把五个核心指数逐个看懂，明确每个指数代表什么以及当前结构意味着什么
2. 再理解市场广度、成交额和行业持续性
3. 形成一套简单的每日、每周市场观察记录
4. 开始设计A池候选规则
5. 再设计B池候选规则
6. 之后进入入场、止损和仓位设计
7. 用小资金和案例记录跑通完整交易流程
8. 根据真实问题继续补充组合、复盘和验证模块
