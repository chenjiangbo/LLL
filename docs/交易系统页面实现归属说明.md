# 交易系统页面实现归属

## 当前唯一生效页面链路

交易系统一级导航进入交易系统后，页面统一由以下链路渲染：

```text
app/page.tsx
  → app/components/TradingSystemShell.tsx
  → app/components/PrototypeTradingPage.tsx
  → public/prototype-pages/<页面目录>/code.html
```

13 个交易系统页面的原型 HTML 映射集中维护在：

```text
app/components/PrototypeTradingPage.tsx
```

后续交易系统页面的视觉、字段、交互和复制行为，必须从这条链路查找和修改。

## 已移出主页面路径的旧实现

以下文件不再作为交易系统主页面使用：

- `app/components/legacy/TradingOverviewPage.tsx`
- `app/components/legacy/TradeLifecycleTable.tsx`

`app/components/TradesPage.tsx` 目前仅保留交易弹窗导出，供交易系统的风险参考和退出规则弹窗使用；它的旧交易列表主体不属于当前页面入口。

## 页面入口约束

- `TradingSystemShell.tsx` 中的原型页面映射是交易系统页面入口。
- 不要根据文件名猜测生效页面。
- 修改前先确认是否经过 `PrototypeTradingPage` 渲染。
