# 交易系统总览 UI 颜色与交互设计参考 V1.1

## 1. 设计原则

交易系统沿用“自动选股”已有的颜色体系。颜色只表达业务含义，不能只为了装饰，也不能代替文字说明。

所有指标卡使用统一的内容层级：标题左上、业务图标右上、核心数值下方大字号显示、补充说明位于核心数值下方；有比例关系的指标使用高对比度进度条。

## 2. 视觉基调

交易系统沿用自动选股页面已经验证的视觉语言：暖白色工作区作为底色，深色高对比卡片承担重点信息，绿色表示系统正常，红棕 / 酒红表示风险或负向状态，蓝紫和琥珀色用于分类与提醒。颜色要有明确的视觉重量，不能把所有内容都处理成白底浅边框。

## 3. 核心配色

| 语义 | 背景 | 文字 | 使用场景 |

## 4. 交易总览指标卡

顶部一行固定使用五张同规格卡片，五张卡片必须保持相同结构：

- 账户净资产：深蓝灰 `#4b5b73`。
- 可用现金：自动选股绿 `#5f8f6e`。
- 当前总仓位：棕金 `#8a6a35`。
- 账户当前总风险：红棕 / 酒红 `#b0003a`。
- 计划风险进度：青灰蓝 `#567a8f`，与 AI 功能使用的紫色区分。

每张卡片都必须使用“标题左上 + 图标右上 + 大号主指标 + 底部说明”的层级。第五张卡片不能改成另一种白底或横向条形结构。

计划风险进度的主指标只显示风险占用百分比：

> 计划风险进度：0.41%

预算金额和预算比例作为底部说明显示，例如“预算金额: ¥38,938.81 · 预算比例: 20.00%”。风险金额属于“账户当前总风险”卡片，不在计划风险进度卡片中重复显示。风险进度条使用浅色轨道和白色填充，不能与青灰蓝背景融为一体。没有预算或关键数据缺失时显示“尚未配置”或“暂无数据”，不显示容易误解的 `0`。

当前总仓位卡片显示当前仓位比例，并同时显示：

> 持仓市值 / 账户净资产

不能只显示持仓股票数量；不再额外显示含义重复的“仓位占用”区块。

## 5. 列表标签

- 交易类型使用独立标签：趋势交易蓝色、反弹 / 波段紫色、固定目标琥珀色、自定义灰色。
- 生命周期使用状态标签：进行中绿色、计划中蓝色、清仓中琥珀色、已结束灰色、已暂停琥珀色。
- 最近动作使用琥珀色标签；无动作使用灰色标签。
- 标签必须同时具备浅色背景、深色文字和边框，不能只依赖文字颜色。

## 6. 红涨绿跌模式

交易总览表格保留“红涨绿跌模式”说明，并按每个持仓的当前价与买入价着色整行：

- 当前价高于买入价：整行浅红色，价格和盈亏使用红色，表示盈利。
- 当前价低于买入价：整行浅绿色，价格和盈亏使用绿色，表示亏损。
- 当前价等于买入价：保持中性背景，不误判为上涨或下跌。
- 任一价格缺失或无效：不强行判断，保持中性背景并显示缺失数据。

## 7. 导航状态颜色

- 左侧菜单选中：使用深绿色 `#2d5a43`。
- 券商已连接的账号图标：使用浅绿色底 `#b8dec0`、深绿色文字，避免与菜单选中状态混淆。
- 券商未连接：使用红色底，明确表示通道异常。
- 暂停执行：使用琥珀色；恢复执行按钮不与菜单选中色复用。

## 8. 导航与交互规则

- “交易系统”一级导航本身是下拉菜单，点击后选择交易账号；未选择账号时不加载单账号页面。
- 下拉菜单显示已有账号，并保留“全部账号”入口；页面尚未建设时明确显示建设中。
- 账号选择后，所有交易页面只读取当前账号数据；刷新页面后仍按当前选择的账号加载。
- 左侧窄导航中的账号和券商状态合并为一个图标，放在“设置”按钮上方。已连接使用浅绿色，未连接使用红色。
- 暂停执行是当前账号的状态，按钮放在账号图标下方、设置按钮上方。
- 右上角刷新数据使用纯图标按钮，同时提供悬停提示和无障碍标签；点击后重新读取当前账号数据。
- “查看”必须携带当前 Trade 上下文进入详情页；没有具体 Trade 时先回到交易列表选择。
- “去设置”必须进入当前账号配置，并能解决触发该提示的配置问题。
- 配置保存后，相关指标必须重新读取并反映在总览页面；只增加输入框但不保存、不参与计算属于未完成。

## 9. 数据缺失与按钮行为

- 核心数据缺失时显示“暂无数据”“尚未配置”或“无法读取”等业务文案，不使用假数据或静默的 `0`。
- 进度条只有在分子、分母和单位明确时才显示有效进度。
- 页面按钮必须执行与按钮名称相符的业务动作；接口失败时明确提示失败原因。
